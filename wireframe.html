Student screens (01–14)

# Screen Route Fields / data collected AI Journeys
01 Home / Landing / (vision: OAuth) Capstone: app home links to intake, demo, counselor. Wireframe: Google/email auth — V2. None All
02 Account / pilot setup /intake (Capstone) Grade + pilot school code (PILOT-A, DEMO); visitor_id. No email login. None first-plan, account
03 Trusted contact setup /setup (V2) Not built in capstone. Wireframe: contact name, email; permissions. None first-plan, account
04 Student dashboard /dashboard (Capstone) POST /api/load-plan by visitor_id. Check-in, toolkit, view plan, update plan (→ 05 pre-fill). “Next step only” LLM — V2. Plan display from saved JSON; update routes to intake return, checkin, first-plan
05 Situation selection /intake/situation (Capstone) Multi-select situation checkboxes; optional 280-char text per selection (screened). Hidden if flagged. Screening → Master (after 06–07) first-plan, flagged
06 Tasks /intake/tasks (Capstone) Per task: name (dropdown), due date, deadline type. Structured only. Feeds master first-plan
07 Clarifying questions /intake/clarify (Capstone) Available time; started status; difficulty; deadline changes since entry. No free text (v5). Feeds master first-plan
08 Plan delivery /intake/plan (Capstone) Displays model output: acknowledgment, full-scope plan, seven-day steps; include/exclude/ask me later per resource; optional share plan. Master output rendered here first-plan, crisis
09 Toolkit view /intake/toolkit (Capstone) Resource cards, open-link clicks (analytics). Not LLM input. None return, checkin
10 Check-in response /intake/check-in (Capstone) Production copy: “How are your tasks going?” — buttons Yes, I finished this · In progress · Not yet · I tried but could not finish; page-level “I want to contact my school counselor.” POST /api/submit-check-in. V2: email token URL; per-task 140-char barrier. Structured only in capstone; adaptive replan LLM — V2 checkin, return
11 Progress summary /intake/progress (Capstone) Summary from check-ins; confidence radio (metrics, not plan prompt). Button to update plan. None (display) checkin, return
12 Crisis resources /support No plan. 988, Crisis Text Line, trusted contact notify (confirmed). Triggered by screening tier or behavioral patterns. UI response to screening / behavior (no plan prompt) crisis, all paths
13 Plan update /intake/situation (Capstone: pre-fill) Capstone: dashboard → situation (05) with prior intake pre-filled → new plan (08). Dedicated /update screen — V2. Screening + master on regenerate return
14 Flagged user state (example) /start Same as 05 without free text fields. Demonstrates account state, not a separate happy-path screen. Master / update / replan without free text flagged

Counselor screens (15–17)

Screen 15 is built (Phase 4): live SQL aggregates from Supabase via POST /api/counselor-aggregates. Demo school DEMO; seed with npm run seed:demo in unstuck-app. Screens 16–17 are wireframe-only in the capstone MVP. Student plan library remains system prompt in v1.

# Screen Route Fields / data AI Journeys
15 Counselor dashboard /counselor/dashboard Production UI (Vercel): Title “Counselor dashboard” only — no school name on screen. Header: grade dropdown (All grades, 9–12). Row: From / To dates, Day of week. Five KPIs: Students with a plan; New plan sessions; Return plan sessions; Resource engagement; Contact requests. Sessions by category (Sessions + % of total columns). Patterns & Actionable Insights (rule-based). Resource engagement High/Med/Low. Backend: DEMO school hardcoded in capstone UI; POST /api/counselor-aggregates. No “Configure resources” button. Rule-based insights only (no aggregate LLM) counselor
16 Resource configuration /counselor/resources Deferred — not in capstone app. Wireframe: school-specific resources by category; AI suggest add resource (prototype). Deferred counselor
17 Contact request notification /counselor/notifications Deferred — not in capstone app. Contact intent counted on screen 15 via check_ins (counselor_contact). Wireframe: student name, timestamp, support flag; session content not shared. Deferred counselor, checkin

Common paths (screen order)

New student → first plan (capstone)

Home → /intake (02) → 05 → 06 → 07 → [screening] → 08 → optional 09 toolkit

Return → plan update (capstone)

/dashboard → update plan → /intake/situation (pre-fill) → 06–08

Check-in (capstone)

Direct: /intake/check-in → /intake/progress (pushed check-in; needs visitor_id on device). Return path: /dashboard → Check in button → same screens. Pilot message link: /intake/check-in — not /dashboard.

Check-in → replan (V2)

Email/SMS token → 10 → 11 → adaptive replan LLM → 08

Return → next step only (V2)

04 → continuation Sonnet call → single next action

Crisis / elevated

Can interrupt after 05, 07, 10, or 13 screening → 12. Plan may exist but delivery gated.
