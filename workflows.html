Primary capstone figure: Matt and Ms. Smith in parallel, with one cross-lane connection when the student requests counselor support.

Two parallel lanes

Matt — student

Primary end user

  1. Discovers Unstuck; creates account and optional trusted contact
  2. First plan via structured intake + AI plan generation
  3. Email check-ins, replan when behind, plan update when life changes
  4. Optionally notifies counselor (name + flag only)

Detail: First session · Check-in & replan

Ms. Smith — counselor

Institutional path · v2 revenue

  1. Organic discovery via student mention
  2. Pilot: compliance review, referrals, aggregate dashboard
  3. Contact requests and pattern observations (no individual session text by default)
  4. Pilot data supports institutional license conversation
Cross-lane link: Student-initiated counselor contact during check-in or support flow. Ms. Smith receives name + support flag, not intake or plan content, unless the student separately shares under trusted-contact permissions.
